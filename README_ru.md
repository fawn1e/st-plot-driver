# Fawn's Plot Driver 📝

Расширение для SillyTavern с искусственным интеллектом, которое помогает генерировать OOC (Out Of Character) инструкции для управления сюжетом.

**Примечание автора**: Я не профессиональный программист, поэтому, пожалуйста, объясняйте любые проблемы простыми словами! 💖

---

## ✨ Возможности

- **Управление сюжетом через ИИ**: Автоматически генерирует OOC инструкции для пропусков времени и сюжетных поворотов.
- **Память по чатам**: Запоминает ваш последний OOC и активные промпты для каждого чата отдельно.
- **Умное понимание контекста**: Использует историю чата для создания релевантных указаний.
- **Настраиваемые промпты**: Настройте инструкции ИИ под разные стили повествования.
- **Система предпочтений**: Добавляйте конкретные детали или требования перед генерацией.
- **Адаптивный дизайн**: Чистый интерфейс, который работает на компьютере и телефоне.
- **Ручной ввод**: Полный контроль с возможностью ручного ввода OOC.
- **Быстрая очистка**: Удаляйте активные OOC промпты одним кликом.

---

## 🚀 Установка

### Простая установка (Рекомендуется)
1. В SillyTavern перейдите в **Расширения → Установить расширение**.
2. Вставьте эту ссылку:  
   `https://github.com/fawn1e/st-plot-driver.git`
3. Нажмите **Установить**.
4. Перезапустите SillyTavern.

### Ручная установка
1. Скачайте файлы расширения.
2. Поместите их в папку расширений SillyTavern:
   ```
   SillyTavern/public/scripts/extensions/third-party/plot-driver-fawn/
   ```
3. Перезапустите SillyTavern.

Всё! Теперь вы должны увидеть значок пера (`✒️`) в интерфейсе чата.

## 📖 Использование

### Основное использование
1. Нажмите на **значок пера** (`fa-pen-nib`) в интерфейсе чата.
2. Выберите из:
   - **⏳ Пропуск времени**: Сгенерировать OOC инструкции для временных скачков.
   - **⚡ Сюжетный поворот**: Создать неожиданные развития сюжета.
   - **⚙️ Настройки**: Настроить промпты и параметры.
### Изменяемые параметры в меню: 
### ⏰ Последний OOC
- **Что это**: Последний сгенерированный, но не применённый OOC для текущего чата.
- **Когда появляется**: Только если вы закрыли окно генерации без нажатия "Применить".
- **Когда исчезает**: Автоматически после отправки сообщения или очистки OOC.
- **Особенность**: Хранится отдельно для каждого чата.
### 🧹 Очистить OOC
- **Что делает**: Полностью удаляет активный OOC-промпт.
- **Когда доступно**: Только после применения OOC, но до отправки сообщения.
- **Когда пропадает**: После отправки сообщения, свайпа или ответа бота.
- **Альтернатива**: Если уже отправили сообщение — просто игнорируйте OOC в ответе бота.
- **✍️ Ручной ввод**: Написать собственные OOC инструкции.

### Система предпочтений
Перед генерацией вы можете указать предпочтения:
- **Пропустить до конкретного времени** (утро, вечер, следующая неделя).
- **Добавить детали персонажей** (конкретные NPC, локации, события).
- **Установить требования сюжета** (типы поворотов, эмоциональный тон, результаты).

Просто введите свои предпочтения во всплывающем окне перед генерацией!

### Предпросмотр и редактирование OOC
После генерации:
1. Просмотрите OOC, сгенерированный ИИ.
2. Отредактируйте текст при необходимости.
3. Примените, чтобы отправить как системный промпт.
4. Перегенерируйте, если не довольны результатом.
5. Отправьте своё сообщение боту — в следующем ответе он применит этот OOC.

## ⚙️ Настройки
Доступ к настройкам через меню для кастомизации:

### Настройка промптов
- **Промпт для пропуска времени**: По умолчанию: *"Вы - мастер архитектуры историй. Создайте естественный пропуск времени, который элегантно продвигает повествование вперёд. Напишите 2–3 предложения как OOC указание."*
- **Промпт для сюжетного поворота**: По умолчанию: *"Вы - гениальный стилист повествования. Представьте неожиданный, но логичный сюжетный поворот. Напишите 2–3 предложения как OOC указание."*

### Настройки контекста
- **Количество сообщений**: Число последних сообщений для использования в контексте (5–50).  
  По умолчанию: 15 сообщений (рекомендую меньше, если боитесь за токены).

Настройки сохраняются **для каждого чата отдельно** — можно иметь разные конфигурации для разных историй.

## 🔧 Как это работает

1. **Определение чата**: Автоматически определяет текущий чат и загружает его настройки и историю OOC.
2. **Сбор контекста**: Собирает последние сообщения чата на основе ваших настроек.
3. **Сборка промпта**: Комбинирует ваши предпочтения с инструкциями ИИ.
4. **Генерация ИИ**: Отправляет промпт в ваш настроенный AI бэкенд.
5. **Извлечение OOC**: Анализирует ответ для извлечения чистых OOC инструкций.
6. **Применение промпта**: Добавляет OOC как системный промпт для следующего ответа ИИ.
7. **Сохранение**: Сохраняет OOC локально для повторного использования в этом же чате.

## 💡 Лучшие практики

### Для пропуска времени:
- Будьте конкретны в продолжительности (*"пропустить до следующего утра"*).
- Упоминайте важные события (*"после того, как они прибывают в замок"*).
- Включайте изменения окружения (*"по мере смены времён года"*).

### Для сюжетных поворотов:
- Предлагайте типы поворотов (*"предательство"*, *"откровение"*, *"неожиданный союзник"*).
- Устанавливайте эмоциональный тон (*"драматичный"*, *"тонкий"*, *"шокирующий"*).
- Учитывайте последствия для развития персонажей.

### Общие советы:
- Используйте предпочтения для конкретных требований.
- Редактируйте сгенерированный OOC под свои точные нужды.
- Комбинируйте несколько OOC инструкций для сложных повествований.
- Используйте **Последний OOC**, чтобы повторно применить успешные промпты.

## 🐛 Устранение неполадок

### Частые проблемы:

**Проблема**: Меню не появляется.  
**Решение**: Попробуйте перезапустить SillyTavern. Убедитесь, что у вас версия 1.10.0+.

**Проблема**: OOC не генерируется.  
**Решение**: Проверьте подключение к вашему AI бэкенду и лимиты токенов.

**Проблема**: Предпочтения не учитываются.  
**Решение**: Пишите предпочтения чётко, кратко и по делу.

**Проблема**: Что-то ещё сломалось?  
**Решение**: Я всё ещё учусь! Пожалуйста, опишите проблему простыми словами, чтобы я могла понять и исправить её. 🙏

### Режим отладки:
Откройте консоль браузера (**F12 → Консоль**) и ищите сообщения, начинающиеся с `"Fawn Plot Driver:"`.

## 🛠️ Технические детали

### Требования:
- SillyTavern 1.10.0+
- Рабочий AI бэкенд (OpenAI, Claude, локальная LLM и т.д.)
- Современный браузер с включённым JavaScript

### Структура файлов:
```
plot-driver-fawn/
├── index.js          # Основная логика расширения
├── manifest.json     # Метаданные расширения
└── README.md         # Этот файл
```

### Интеграция API:
Использует API расширений SillyTavern:
- `generateQuietPrompt()` для вызовов ИИ
- `setExtensionPrompt()` для применения OOC
- `getContext()` для доступа к истории чата
- `localStorage` для сохранения данных по чатам
