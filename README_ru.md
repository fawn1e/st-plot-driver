# Fawn's Plot Driver 📝

Расширение для SillyTavern с искусственным интеллектом, которое помогает генерировать OOC (Out Of Character) инструкции для управления сюжетом.

**Примечание автора**: Я не профессиональный программист, поэтому, пожалуйста, объясняйте любые проблемы простыми словами! <3

## Возможности ✨
- **Управление сюжетом через ИИ**: Автоматически генерирует OOC инструкции для пропусков времени и сюжетных поворотов
- **Умное понимание контекста**: Использует историю чата для создания релевантных указаний
- **Настраиваемые промпты**: Настройте инструкции ИИ под разные стили повествования
- **Система предпочтений**: Добавляйте конкретные детали или требования перед генерацией
- **Минималистичный дизайн**: Чистый интерфейс, адаптированный под тему SillyTavern
- **Ручной ввод**: Полный контроль с возможностью ручного ввода OOC

## Установка 🚀
### Простая установка (Рекомендуется)
1. В SillyTavern перейдите в **Расширения → Установить расширение**
2. Вставьте эту ссылку:  
   `https://github.com/fawn1e/st-plot-driver.git`
3. Нажмите **Установить**
4. Перезапустите SillyTavern

### Ручная установка
1. Скачайте файлы расширения
2. Поместите их в папку расширений SillyTavern:
   ```
   SillyTavern/public/scripts/extensions/third-party/plot-driver-fawn/
   ```
3. Перезапустите SillyTavern

Всё! Теперь вы должны увидеть значок пера (`✒️`) в интерфейсе чата.

## Использование 📖
![interface](menu.png)

### Основное использование
1. Нажмите на значок пера (`fa-pen-nib`) в интерфейсе чата
2. Выберите из:
   - **⏳ Пропуск времени**: Сгенерировать OOC инструкции для временных скачков
   - **⚡ Сюжетный поворот**: Создать неожиданные развития сюжета
   - **✍️ Ручной ввод**: Написать собственные OOC инструкции
   - **⏰ Последний OOC**: Просмотреть и повторно использовать последний сгенерированный OOC
   - **⚙️ Настройки**: Настроить промпты и параметры

### Система предпочтений
![interface](prefs.png)

Перед генерацией вы можете указать предпочтения:
- **Пропустить до конкретного времени** (утро, вечер, следующая неделя)
- **Добавить детали персонажей** (конкретные NPC, локации, события)
- **Установить требования сюжета** (типы поворотов, эмоциональный тон, результаты)

Просто введите свои предпочтения во всплывающем окне перед генерацией!

### Предпросмотр и редактирование OOC
![generation](generation.png)

После генерации:
1. Просмотрите OOC, сгенерированный ИИ
2. Отредактируйте текст при необходимости
3. Примените, чтобы отправить как системный промпт
4. Перегенерируйте, если не довольны результатом
5. Отправляйте свой ответ боту, а в следующем сообщении он применит эту ООС

## Настройки ⚙️
Доступ к настройкам через меню для кастомизации:

### Настройка промптов
- **Промпт для пропуска времени**: По умолчанию: "Вы - мастер архитектуры историй. Создайте естественный пропуск времени, который элегантно продвигает повествование вперёд."
- **Промпт для сюжетного поворота**: По умолчанию: "Вы - гениальный стилист повествования. Представьте неожиданный, но логичный сюжетный поворот."

### Настройки контекста
- **Количество сообщений**: Число последних сообщений для использования в контексте (5-50)
- По умолчанию: 15 сообщений (я советую поменьше, чтобы не кушало токены, но если чат большой - дерзайте с побольше)

## Как это работает 🔧
1. **Сбор контекста**: Собирает последние сообщения чата на основе ваших настроек
2. **Сборка промпта**: Комбинирует ваши предпочтения с инструкциями ИИ
3. **Генерация ИИ**: Отправляет промпт в ваш настроенный AI бэкенд
4. **Извлечение OOC**: Анализирует ответ для извлечения чистых OOC инструкций
5. **Применение промпта**: Добавляет OOC как системный промпт для следующего ответа ИИ

## Лучшие практики 💡
### Для пропуска времени:
- Будьте конкретны в продолжительности ("пропустить до следующего утра")
- Упоминайте важные события ("после того, как они прибывают в замок")
- Включайте изменения окружения ("по мере смены времён года")

### Для сюжетных поворотов:
- Предлагайте типы поворотов ("предательство", "сталкерство", "неожиданный влюблённость от НПС")
- Устанавливайте эмоциональный тон ("драматичный", "тонкий", "life changing")
- Учитывайте последствия для развития персонажей

### Общие советы:
- Используйте предпочтения для конкретных требований
- Редактируйте сгенерированный OOC под свои точные нужды
- Комбинируйте несколько OOC инструкций для сложных повествований
- Сохраняйте часто используемые предпочтения как шаблоны

## Устранение неполадок 🔧

### Частые проблемы:

**Проблема**: OOC не генерируется правильно
**Решение**: Проверьте подключение к вашему AI бэкенду и лимиты токенов

**Проблема**: Предпочтения не учитываются
**Решение**: Убедитесь, что предпочтения чётко написаны и релевантны контексту

**Проблема**: Меню не появляется
**Решение**: Попробуйте перезапустить SillyTavern и проверьте консоль на ошибки

**Проблема**: Что-то ещё сломалось?
**Решение**: Я всё ещё учусь! Пожалуйста, опишите проблему простыми словами, чтобы я могла понять и исправить её. 🙏

## Технические детали 🛠️

### Необходимо:
- SillyTavern 1.10.0+
- Рабочий AI бэкенд (OpenAI, Claude, Local LLM и т.д.)
- Браузер с поддержкой JavaScript (самые популярные поддерживают, не боись)

### Структура файлов:
```
plot-driver-fawn/
├── index.js          # Основная логика расширения
├── script.js         # Дополнительная функциональность
├── manifest.json     # Метаданные расширения
└── README.md         # Этот файл
```

### Интеграция API:
Использует API расширений SillyTavern:
- `generateQuietPrompt()` для вызовов ИИ
- `setExtensionPrompt()` для применения OOC
- `getContext()` для доступа к истории чата
